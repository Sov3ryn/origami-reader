## プライバシー

Origami Reader は、あなたのコンピューター上で動作します。アカウント、広告、分析、追跡は一切ありません。あなたが自分でオンラインサービスを接続しない限り（「あなたが接続するオンラインサービス」を参照）、あなたの本、メモ、録音、音声、設定はあなたのコンピューター上にとどまり、AI モデルもそこで実行されます。

本アプリがインターネットに接続するのは、次の場合に限られます。

- 自動更新が有効になっている場合、またはあなたが自分で確認する場合に、GitHub（Sov3ryn/origami-updates）から更新を確認し、ダウンロードするとき。
- あなたが選択したモデル、音声または Studio のパーツを、その公開元（Hugging Face、GitHub、Stability AI）または Origami の音声リポジトリからダウンロードするとき。
- あなたがリンクを開くとき、ワークモードで埋め込みを許可するとき、またはサポートページを開くとき。
- あなたが自分で接続したオンラインサービスに、処理を依頼したものを送信するとき。

セットアップでも、あなたが選択したパーツをその公開元から、また Python パッケージを PyPI および PyTorch から（AMD のグラフィックカードを搭載したコンピューターでは AMD からも）ダウンロードします。これらのサービスは、それぞれのプライバシーポリシーに従い、あなたのコンピューターのネットワークアドレスと、ダウンロードされるものを知ることになります。Sov3ryn は、GitHub が各リリースについて表示するダウンロード数を除き、これらの情報を一切受け取りません。フィードバックや問題報告を送信する場合、その内容はあなたが選択します。

寄付をする場合、Ko-fi およびその決済事業者が、それぞれの条件に従ってあなたの支払いを処理します。Sov3ryn は Ko-fi が共有する情報（あなたの名前、メールアドレス、メッセージなど）を受け取り、それをあなたへのお礼と、お礼のアイテムのロック解除のためにのみ使用します。
