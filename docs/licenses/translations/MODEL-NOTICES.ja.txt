Origami Reader：モデルと音声
============================

Origami Reader がインストールまたはダウンロードする AI モデルは他者が作成した
もので、それぞれ独自のライセンスが適用されます。Origami のライセンス
（LICENSE および APP-LICENSE.md）はこれらのモデルを対象とせず、それらの
ライセンスがあなたに与える権利を奪うこともありません。Origami がモデルを
インストールする場合、そのライセンスまたは通知のコピーがモデルファイルの横に
置かれます。Apache License 2.0、CreativeML OpenRAIL-M ライセンスおよび
Stability AI Community License の全文は、「設定」>「情報とサポート」>
「著作権とライセンス」でも確認できます。

モデルは公開元（主に Hugging Face）から固定されたリビジョンでダウンロードされ、
使用前に SHA-256 フィンガープリントと照合されます。以下の「改変なし」とは、
公開されているファイルをそのまま使用していることを意味します。


音声合成
--------

Qwen3-TTS 12Hz 0.6B Base、Qwen3-TTS 12Hz 1.7B Base および Qwen3-TTS 12Hz 1.7B
VoiceDesign、Alibaba Cloud の Qwen チーム作成。
  ライセンス：Apache License 2.0。改変なし。
  https://huggingface.co/Qwen/Qwen3-TTS-12Hz-0.6B-Base
  https://huggingface.co/Qwen/Qwen3-TTS-12Hz-1.7B-Base
  https://huggingface.co/Qwen/Qwen3-TTS-12Hz-1.7B-VoiceDesign

Kitten TTS Mini 0.8 および Kitten TTS Micro 0.8、KittenML 作成。
  ライセンス：Apache License 2.0。改変なし。
  https://huggingface.co/KittenML/kitten-tts-mini-0.8
  https://huggingface.co/KittenML/kitten-tts-micro-0.8

Kokoro-82M とその音声ファイル、hexgrad 作成。
  ライセンス：Apache License 2.0。改変なし。
  https://huggingface.co/hexgrad/Kokoro-82M

Kitten と Kokoro は軽量読み上げプログラム（workers/light_tts.py）で動作します。
このプログラムは phonemizer と espeak-ng を使用しているため、GNU General Public
License バージョン 3 またはそれ以降のバージョンのもとで提供される独立した
プログラムです。「設定」の「軽量読み上げ」および workers/LIGHT-READER-SOURCE.txt
を参照してください。

Origami の音声。Origami に付属する音声（音声パックと音声ライブラリ）は、
Sov3ryn が文章による説明をもとに Qwen VoiceDesign で設計した合成音声です。
実在の人物の録音ではなく、誰かを模倣するために作られたものでもありません。
これらはアプリの一部であり、APP-LICENSE.md の対象です。

作成したもの
------------

朗読、音声、画像、話者の割り当て、書き起こしは AI モデルによって作成されるため、
誤りを含む場合があります。Studio のエクスポートには、AI 生成であることが表示
されます（「Made with Origami Reader」のクレジット、AI メタデータ、および音声の
場合は AudioSeal の透かし）。モデルのライセンス（その使用制限を含みます）は、
それらのモデルで作成したものに適用されます。
