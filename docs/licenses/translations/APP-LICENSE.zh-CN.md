Origami Reader 在您的电脑上使用 AI 模型来朗读、设计语音、制作图片、识别说话人和转写录音，并可能在后续版本中将其用于更多用途。它们制作的内容可能有误。本应用会通过署名、元数据或水印，将其导出的内容标记为 AI 生成。

- 请仅使用您有权使用的内容。您须对您导入的书籍、文档和录音以及您使用本应用制作和分享的内容负责。
- 请勿使用本应用在未经真实人物明确许可的情况下制作模仿该人物的语音，也不得使用本应用制作冒充、欺骗、骚扰或诽谤任何人的内容或违反法律的内容。

- 在您分享的所有内容上，请保留本应用添加的署名、AI 标签和水印。当您发布使用本应用的 AI 制作的任何内容时，如法律或平台有此要求，请注明其为 AI 生成。

## 隐私

Origami Reader 在您的电脑上运行。它没有账户、没有广告、没有分析，也没有跟踪。除非您自行连接在线服务（参见“您连接的在线服务”），您的书籍、笔记、录音、语音和设置都保留在您的电脑上，AI 模型也在您的电脑上运行。

本应用仅在以下情况下连接互联网：

- 在自动更新开启或您自行检查时，从 GitHub（Sov3ryn/origami-updates）检查并下载更新；
- 从发布者（Hugging Face、GitHub、Stability AI）或 Origami 语音仓库下载您选择的模型、语音或 Studio 组件；
- 当您打开链接、在工作模式中允许嵌入内容或打开支持页面时；
- 向您自行连接的在线服务发送您要求其处理的内容。

安装过程中也会从发布者处下载您选择的组件，并从 PyPI 和 PyTorch（在配备 AMD 显卡的电脑上还包括 AMD）下载 Python 软件包。这些服务会依据其各自的隐私政策看到您电脑的网络地址以及所下载的内容。除 GitHub 为每个版本显示的下载次数外，Sov3ryn 不会收到任何此类信息。如果您发送反馈或问题报告，其内容由您决定。

如果您进行捐助，Ko-fi 及其支付服务提供商将依据其各自的条款处理您的付款。Sov3ryn 会收到 Ko-fi 共享的信息（例如您的姓名、电子邮件和留言），并仅将其用于向您致谢和为您解锁致谢物品。
