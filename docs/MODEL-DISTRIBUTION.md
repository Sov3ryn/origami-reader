A free Origami installer can include this checkpoint as a separate licensed file. Origami's own license (PolyForm Strict 1.0.0 for the source, APP-LICENSE.md for the app) covers only Origami. The weights retain CreativeML OpenRAIL-M; bundling them does not bring them under Origami's terms.

OpenRAIL-M [section 4](https://huggingface.co/spaces/CompVis/stable-diffusion-license/blob/main/license.txt) permits model redistribution subject to conditions. The release must include the full model license, copyright and applicable attribution notices. Section 5 and Attachment A restrictions must be enforceable under the terms governing model use and distribution, with notice to recipients that those conditions apply. Apply these model terms to the weights and their use, kept separate from Origami's own license terms. The setup script copies the full license and a model notice beside the checkpoint. The future public installer must present the model's terms when the model is installed or enabled. Shipping a license file alone does not settle all of the model's downstream agreement requirements.

Keep these items together in a model folder: the unchanged checkpoint, CreativeML-OpenRAIL-M.txt and MODEL-NOTICE.txt identifying Lykon, the upstream URLs, model version and checksum. Preserve notices and mark any modified weight files if a future release converts or changes them. A public binary release must carry Origami's license notices. The native runtime and other dependencies retain their licenses.

The author lists commercial image use and rental/service permissions, but not model-sale permission. Treat selling the checkpoint itself as disallowed under that release's permissions. A paid installer or paid software bundle containing weights should get clarification or permission from the author before shipping; this free-bundle review does not clear that scenario. Origami's own terms do not override model terms.

Origami's intended pricing is pay what you want, starting at zero. Do not extend the free-bundle conclusion to that payment-linked release automatically. Clarify with the author whether the planned installer containing weights is permitted, or select a model with clear permission for that distribution. This is an unresolved release requirement, not a determination that every optional donation arrangement constitutes model selling. Local image generation remains configured as before.

This update changes local generation and setup. It does not publish an installer, place model weights in Git, or claim clearance for every distribution scenario. Books, speech models and voice recordings have separate terms.
