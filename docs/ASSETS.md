# Asset provenance

- assets/branding/crane-master.png: AI-generated faceted lavender paper crane recreated from the approved library concept using the built-in image generation tool. Replaced the initial simplified vector after user feedback.
- public/crane.png: small raster export from that master for the interface.
- public/ambient/petal.svg, mist.svg, ripples.svg and cloud.svg: original small vector sprites with transparent gradients, authored for the optional lake overlays. The cloud silhouette follows the thin, irregular wisps in the background artwork. They have no external resources or runtime SVG filters. The cabin light is a small CSS radial gradient aligned with the painted window.
- public/moonlit-lake.png: original AI-generated reading background created with the built-in image generation tool on 12 October 2026. No external source image was used. Included with the app's MPL 2.0 grant to the extent rights are held by the contributors.
- public/backgrounds/spring-morning.png, summer-evening.png, autumn-dusk.png and winter-daylight.png: seasonal edits of public/moonlit-lake.png made with the built-in image generation tool on 12 October 2026. The original camera, shore, mountains and cabin locations are preserved. Included under the same asset grant. Exact prompts and saved paths are in SEASONAL-PROMPTS.md.
- public/ambient/leaf.svg and day-cloud.svg: original small vector overlays with no external resources or runtime SVG filters. Snowflakes and fireflies use small static CSS gradients with transform/opacity animation. Summer fish-feeding rings are CSS ellipses with static borders and shadows, animated through transforms and opacity.
- src-tauri/icons: raster exports from the crane master, generated by the Tauri icon tool.
- src/seeds.ts: original short demonstration passages. Titles and author names are fictional UI examples, not imported published books.
- assets/starter-library: five historical English text EPUBs from pinned Standard Ebooks revisions, with all known original text contributors deceased before 1925, plus Grayson's Book of Stories, a sixteen-story contemporary collection expressly licensed for commercial reuse by Grayson Bray Morris under CC BY-SA 4.0 International. Standard Ebooks contributions remain CC0. No source artwork, fonts or logos are included; Verne's three runic diagrams retain their supplied descriptions. RIGHTS.txt, international-review.json and the manifest record scoped territorial rules, unresolved special-fee cases, source revisions and hashes. Release packaging requires a reviewed destination and excludes stale or removed book assets. This material is separate from Origami's MPL 2.0 code grant; no unconditional worldwide clearance is claimed.
- docs/Origami-Library.png and docs/Origami-Reader.png: original AI-generated design concepts, not screenshots of the implemented app. Their decorative text is not a product-copy specification.
- docs/screenshots: screenshots of the implemented interface.

Voice references, generated personal speech and model weights are excluded from the public repository. The MPL 2.0 code license does not grant rights to someone else's voice pack or model.

## Background generation prompt

Original atmospheric background artwork for a premium desktop reading app called Origami. No text, no logo, no user interface. Wide composition with a moonlit lake, charcoal plum and midnight indigo, distant layered mountains, restrained moon reflection and a small warm window across the water. Plum blossom branches frame the edges. Low contrast through the center, painterly illustration with folded-paper-like distant planes. Quiet background for a reading surface, no people or borders.

## Crane generation prompt

Extract and recreate only the folded origami paper crane logo from the top left of the approved library mockup. Isolated app brand asset on transparent square canvas. Match the tall sharply pointed raised right wing, broad diagonally raised left wing, folded central diamond body and slender right-facing neck and beak. Lavender and pale lilac facets, smoky violet shadows, crisp polygon edges, no outline, external shadow, text or badge. Keep the reference proportions and approximately ten percent transparent padding. Remain readable at 40 to 64 pixels.
