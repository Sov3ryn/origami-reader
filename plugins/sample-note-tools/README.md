# Note tools (sample plugin)

A small plugin that shows what Origami plugins can do:

- a panel with statistics for the open note (words, sentences, reading time, frequent words);
- commands in Search (Ctrl+K): "Note statistics", "Insert a table of contents", "Insert today's date".

It asks for `notes:read` (to read the open note) and `notes:write` (to insert text).
Copy this folder to start your own plugin; see docs/PLUGINS.md.
